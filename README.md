# Виселица (Hangman) — консольная игра на Python

Консольная реализация классической игры «Виселица», созданная в учебных целях.  
Игроку предлагается угадать загаданное слово, открывая его по буквам. При каждой ошибке уменьшается количество доступных попыток. После их исчерпания игра завершается поражением.

Проект демонстрирует базовые принципы программирования на Python: работу с циклами, множествами, строками, обработку пользовательского ввода и построение простого игрового алгоритма.

---

## ⚙️ Используемые технологии

- **Язык программирования:** Python 3  
- **Стандартные библиотеки Python**  
- **Консольный интерфейс без графических зависимостей**

---

## 📌 Возможности

- Случайный выбор слова из словаря
- Отображение текущего состояния (угадываемые буквы и подчёркивания)
- Учёт использованных букв
- Ограничение числа неверных попыток
- Проверка корректности ввода
- Поддержка выхода из игры командой `quit`
- Простая структура кода, удобная для расширения
